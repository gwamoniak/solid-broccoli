02Sensor device stack (UML)

Sensor-neutral below the service layer: transports move bytes, sans-IO codecs parse them, one generic CodecDevice pairs them. A new modality = one codec + one semantic subclass; Milestone 10 (Geiger) changed zero lines of this plumbing.

classDiagram
    class SensorTransport {
        <<abstract>>
        +open(errorMessage) bool
        +close() void
        +writeBytes(bytes) void
        +bytesReceived(bytes) signal
        +transportError(message) signal
        +closed() signal
    }
    class ProtocolCodec {
        <<abstract>>
        +feed(bytes) void
        +setSink(fn~SensorReading~) void
        +encodeStart() QByteArray
        +encodeStop() QByteArray
        +encodeParams(AcquisitionParams) QByteArray
    }
    class SensorDevice {
        <<abstract>>
        +connectDevice(errorMessage) bool
        +start() void
        +stop() void
        +setParams(AcquisitionParams) void
        +spectrumReady(Spectrum) signal
        +readingReady(GeigerReading) signal
        +errorOccurred(message) signal
    }
    class CodecDevice {
        pairs one transport with one codec
    }
    class SimulatedSpectrometer {
        SimScene + InstrumentModel
    }
    class SimulatedGeiger {
        seeded Poisson tube
    }
    class BleTransport {
        QLowEnergyController central
    }
    class SimulatedBridgeTransport {
        byte-level firmware impersonation
    }
    class BridgeFrameParser {
        shared framing + byte-wise resync
    }
    class As7265xCodec {
        frame type 0x01
    }
    class GeigerCodec {
        frame type 0x02
    }

04Camera & vision pipeline

One plugin interface, three jobs: filters, instrumentation overlay, ML detection. Inference is decoupled — every Nth frame on a pool thread, freshest boxes drawn on every frame, so the preview never blocks on the model.

05Persistence

One SQLite file under the platform app-data root. Cascades are explicit in DAO code; spectra store raw float64 blobs; reports.context_json keeps every AI report auditable.

06AI report generation

Grounding first, language second: deterministic code produces every factual claim, the model narrates an immutable match table, and the exact input JSON is stored with the report. Greedy sampling, pinned llama.cpp, versioned prompt.

sequenceDiagram
    actor U as User
    participant P as SessionDetailPage.qml
    participant R as ReportService
    participant B as ReportContextBuilder
    participant M as PeakMatcher
    participant A as AiAnalyst worker
    participant D as ReportDAO

    U->>P: Generate AI report
    P->>R: generateReport(sessionId)
    R->>B: build(session, spectra, measurements, detections)
    B->>M: match peaks vs reference library
    M-->>B: ranked candidates
    B-->>R: context JSON
    R->>A: lazy loadModel, then generate(prompt + context)
    loop token stream
        A-->>P: tokenGenerated
    end
    A-->>R: generationFinished(markdown)
    R->>D: addReport(context_json + content_md)
    R-->>P: reportSaved

07Threading map

SQLite only on the GUI thread; frame processing on the camera worker; inference on the pool; llama.cpp on its own thread. Cross-thread traffic = mutexed snapshots one way, queued signals the other.
